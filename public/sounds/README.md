# Moshi greeting audio

Place a short MP3/WAV file here named:

**`moshi-moshi.mp3`**

Requirements for the voice:
- Speaks exactly: **"Moshi Moshi"**
- Clear, high-energy **child's voice**
- Cheerful and engaging
- Duration ~1–1.5 seconds recommended
- Sample rate 44.1kHz or 48kHz, mono or stereo

You can generate it with:
- ElevenLabs / PlayHT / Google Cloud TTS (child voice)
- A recorded take from a child actor (with permission)
- Any TTS tool with a "child" or high-pitch cheerful preset

If the file is missing, the splash falls back to the browser Speech Synthesis API
(with higher pitch / rate — not a true child voice).
